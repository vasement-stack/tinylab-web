隱私權政策

適用於 YouOwn 帳單管家（iOS App 與網頁版）。生效日期：2026 年 11 月 14 日。

簡短版

YouOwn 在你的裝置上運作，你的帳單與消費資料存放在你自己的 Google 試算表。這些資料不會經過、也不會存放在開發者的伺服器，開發者無法看到你的信件、帳單或試算表內容。

YouOwn 會存取哪些資料

登入時，你會授權 YouOwn 使用以下三項 Google 權限：

  • Gmail 唯讀（gmail.readonly）：YouOwn 只搜尋來自銀行與電子發票平台寄件網域的通知信，在你的裝置上解析出帳單、消費、發票與轉帳的金額、日期、商家等記帳所需資訊。YouOwn 不會寄信、刪信或修改你的信件。
  • Google 雲端硬碟檔案（drive.file）：用來建立並讀寫 YouOwn 自己的試算表。這個權限只涵蓋由 YouOwn 建立的檔案，YouOwn 看不到你雲端硬碟裡的其他檔案。
  • 帳號電子郵件（userinfo.email）：用來顯示你目前登入的 Google 帳號。

資料存放在哪裡

  • 解析後的帳單、消費、發票、轉帳與分類設定，寫入你自己 Google 帳號中的試算表。
  • 登入用的存取權杖只保存在你的裝置上。
  • YouOwn 沒有自己的資料庫，開發者不保存你的任何財務資料。

YouOwn 不會做的事

  • 不出售你的資料，也不與任何第三方分享。
  • 不將 Google 使用者資料用於廣告，包括個人化或再行銷廣告。
  • 不使用這些資料訓練任何 AI 或機器學習模型。
  • 不會由人工讀取你的資料。除非你自己主動提供（例如把錯誤訊息貼給開發者協助排除問題）。

第三方服務

  • Google：登入、Gmail 與試算表都透過 Google 的 API 進行，適用 Google 的隱私權政策。
  • Vercel：網頁版由 Vercel 託管，Vercel 可能記錄一般的網站連線紀錄（例如 IP 位址），這些紀錄不包含你的帳務內容。
  • Apple：若 App 提供內購項目，付款由 Apple 處理，開發者不會取得你的付款資訊。
  • PDF.js：YouOwn 使用開源的 PDF.js 程式庫，在你的裝置上讀取 PDF 帳單。這個程式庫從第三方的內容傳遞網路（CDN）載入，載入時該服務可能看到一般連線資訊（例如 IP 位址）；你的 PDF 檔案內容不會被傳送出去。

撤銷授權與刪除資料

  • 撤銷授權：到 Google 帳號的「安全性」→「你的第三方應用程式與服務」，移除 YouOwn，YouOwn 就無法再存取你的 Gmail 與試算表。
  • 刪除資料：你的記帳資料在你自己的 Google 雲端硬碟裡，直接刪除該試算表即可。開發者沒有任何備份。
  • 刪除裝置上的資料：登出 App 或移除 App，就會清除保存在裝置上的登入資訊。

Google API 服務使用者資料政策聲明

YouOwn 對從 Google API 取得的資訊的使用與轉移，將遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

YouOwn's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
