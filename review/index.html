示範檔案 Demo files

給 App 審核與試用用的虛構帳單與發票。所有姓名、金額與商店皆為示範資料，不是真實帳單。
Fictional sample bills and invoices for App Review and trying the app. All names, amounts and merchants are made up.

怎麼用 How to use

  • 在 iPhone 的 Safari 開啟本頁，點下面的檔案，再按分享 → 選「YouOwn」，就會直接開啟匯入畫面。Open this page in Safari on iPhone, tap a file, then Share → YouOwn.
  • 如果分享選單沒看到 YouOwn：先存到「檔案」App，再從檔案 App 長按檔案 → 分享 → YouOwn。If YouOwn is not listed, save the file to the Files app first, then share it from there.
  • 兩份 PDF 的密碼都是 demo1234。Both PDFs use the password demo1234.
  • 先匯入兩份 PDF，再匯入發票 CSV：發票會自動配對到帳單明細，沒配到的可在「發票」頁按「補記支出」。Import the two PDFs first, then the invoice CSV.
